# Purple Weather

Погода в объёмном фиолетовом стиле. Без рекламы и аккаунтов.

- Любой город мира: поиск, список своих городов (листаются свайпом), «Моё местоположение».
- Сейчас, по часам (24 ч), на 10 дней с общей шкалой температур.
- Детали: ощущается как, влажность, ветер с направлением, давление (мм рт. ст.), УФ, облачность и осадки, восход/закат, световой день.
- 3D: объёмные анимированные иконки погоды, стеклянные карточки, «выдавленная» температура, параллакс и поворот от наклона телефона, живой фон (звёзды ночью).
- Офлайн: последний прогноз каждого города сохраняется.
- Автообновление из GitHub Releases этого репозитория (репозиторий должен быть публичным).

Данные: [Open-Meteo](https://open-meteo.com) (CC BY 4.0), названия мест — OpenStreetMap / Photon.

Сборка: каждый пуш в `main` собирает APK в GitHub Actions и публикует его в Releases. Версия растёт сама, подпись постоянная (`app/purpleweather.jks`).
